语音 PTT

按住说，松手写

全局快捷键驱动，按下开始录音，松开结束。识别结果自动注入当前焦点应用，无需离开当前工作流。

// 快捷键行为

按住 Option + Space → 开始录音

松开 Option + Space → 停止录音，自动注入

录音中再次按下 → 取消

多路径注入

四种方式，任意场景

Auto 智能兼容、模拟打字、剪贴板粘贴、AppleScript — 根据场景自动或手动选择最合适的注入策略。

// 注入模式

Auto → 智能选择（推荐）

打字 → 逐字模拟键盘

粘贴 → 剪贴板注入

AppleScript → macOS 兼容 fallback

输出后处理

完整功能清单

历史记录

每次语音输入自动保存到本地历史，可搜索、可导出、可清空回看。

词库同步

个人词库与云端双向同步，在不同设备间保持一致的专业术语和自定义词汇。

设置持久化

所有设置、快捷键绑定、注入模式偏好本地持久化存储，重启后自动恢复。

跨应用注入

在任何应用中都能使用 — 编辑器、聊天软件、浏览器表单，一个快捷键，全局可用。

焦点恢复

注入完成后自动恢复原始焦点窗口和光标位置，不打断你的工作流。

剪贴板备份

使用剪贴板注入前自动备份原剪贴板内容，注入完成后自动恢复，保护你的剪贴板数据。

多快捷键绑定

为不同功能分配不同快捷键 — 语音输入、编辑录音、AI 助手、粘贴上一条结果、打开历史记录。

使用统计

追踪你的语音输入数据。每日统计、输入字数、节省时间的估算。

本地数据

所有配置、历史记录、词库均本地存储。你的数据，你做主。
